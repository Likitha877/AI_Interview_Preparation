AI INTERVIEW PREPARATION APPLICATION
====================================

PROJECT DESCRIPTION
-------------------

AI Interview Preparation is a Streamlit-based application
that helps students prepare for technical, HR and coding
interviews.

FILES
-----

app.py
Main application file.

questions.py
Contains technical, HR and coding questions.

database.py
Stores interview results.

requirements.txt
Contains required Python packages.

results.csv
Created automatically after completing an interview.


INSTALLATION
------------

Open the VS Code terminal.

Run:

pip install -r requirements.txt


RUN THE APPLICATION
-------------------

Run:

streamlit run app.py


FEATURES
--------

1. Home
2. Technical Interview
3. HR Interview
4. Coding Interview
5. Results and Performance


TECHNOLOGIES
------------

Python
Streamlit
Pandas
CSV DatabaseS
