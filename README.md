🤖 AI Interview Preparation Application

📌 Project Overview

The AI Interview Preparation Application is a Python-based web application developed using Streamlit. It helps users practice interview questions, prepare for technical and HR interviews, solve coding questions, and review their interview performance.

The application provides a simple, interactive interface to support interview preparation.

✨ Features

- 🏠 Home: Main page for accessing the application.
- 💻 Technical Interview: Practice technical interview questions.
- 👔 HR Interview: Prepare for common HR interview questions.
- 👨‍💻 Coding Interview: Practice coding-related questions.
- 📊 Results and Performance: Review interview results and track performance.

🛠️ Technologies Used

- Python – Application logic
- Streamlit – Web interface
- Pandas – Data handling
- CSV – Storing interview results

📁 Project Structure

- "app.py" – Main application file
- "questions.py" – Contains interview questions
- "database.py" – Handles interview result storage
- "requirements.txt" – Lists required Python packages
- "results.csv" – Stores interview results when generated

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/Likitha877/AI_Interview_Preparation.git

2. Open the project folder

cd AI_Interview_Preparation

3. Install dependencies

pip install -r requirements.txt

4. Run the application

streamlit run app.py

The application should open in your web browser. If it does not, open the local URL displayed in your terminal.

🎯 Project Objective

The objective of this project is to provide an accessible platform for students and job seekers to practice interview questions, improve their preparation, and review their performance.
